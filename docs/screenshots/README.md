# Screenshot Checklist

Capture these images after running the app locally. Use PNG files and keep private information out of the screenshots.

Included files:

1. `01-login.png` - login page
2. `02-public-home.png` - public home/registration entry page

Recommended additional files:

1. `03-dashboard.png` - admin dashboard after login
2. `04-applicants.png` - applicant list or applicant profile
3. `05-companies.png` - company list or company form
4. `06-resume-pdf.png` - generated resume/PDF screen or downloaded PDF preview

Suggested capture steps:

1. Run `php spark serve`.
2. Open `http://localhost:8080`.
3. Log in with `admin` / `admin123`.
4. Capture each screen at a readable desktop width.
5. Blur or replace any real personal data before committing.
